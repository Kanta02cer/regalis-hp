Adctor（HackⅡ AI Search Monitor / AI Access Gateway 等）販売代理店契約

レガリスジャパングループ株式会社（Trillion Bank株式会社）〔正式社名は要確認〕（以下「甲」という。）と、 （以下「乙」という。）とは、甲が提供するサービス「Adctor」（HackⅡ AI Search Monitor、AI Access Gateway、Usage / Citation Ledger 等をいい、以下総称して「本サービス」という。）の販売に関する販売代理店取引について、以下のとおり基本契約（以下「本契約」という。）を締結する。

第1条（目的）

  1. 本契約は、甲が乙に対し本サービスの販売を委託し、乙がこれを自己の顧客（以下「エンドユーザー」という。）に対して販売・提案・導入支援するにあたっての基本的事項を定めることを目的とする。
  2. 個別の取引に関する具体的条件は、本契約に加え、甲乙間で別途合意する個別契約、注文書、料金表（別紙1）、その他の付属文書（以下「個別契約等」という。）により定める。本契約と個別契約等の内容が矛盾する場合、個別契約等が優先する。

第2条（定義）

  1. 「本サービス」とは、AI検索上の露出・引用・競合状況の測定（HackⅡ）、AIクローラー等のアクセス可視化・制御・利用ログ・請求に関する機能（AI Access Gateway / PPC）、及びこれらに付随する診断・レポート・運用支援サービスをいう。
  2. 「診断」とは、初回に提供するAI検索診断／AIクローラー診断等のスポット役務をいう。
  3. 「月次サービス」とは、月額課金により継続提供するモニタリング・運用・レポート役務をいう。
  4. 「卸価格」とは、甲が乙に対して本サービスを提供する対価をいい、別紙1に定める。
  5. 「エンド販売価格」とは、乙がエンドユーザーに販売する価格をいう。
  6. 「ホワイトラベル提供」とは、乙のブランドで本サービス（主にレポート）を提供することをいう。

第3条（販売代理店の任命／非独占）

  1. 甲は乙を本サービスの非独占的販売代理店として任命し、乙はこれを受諾する。甲は乙以外の第三者を代理店に任命し、又は自ら直接販売することを妨げられない。
  2. 特定地域・特定業種における独占的取扱いは、別途書面により合意した場合に限り認められる。
  3. 乙は、あらかじめ甲の書面による承諾を得ずに、本サービスの再販売権を第三者（二次代理店を含む）に付与してはならない。

第4条（提供モデル）

乙は、次の各号のいずれか又は組合せにより本サービスを取り扱うことができる。適用モデルは個別契約等で定める。

  1. ホワイトラベル型：乙のブランドでエンドユーザーに提供する（OEM条件は別途合意）。
  2. 共同提案型：甲が商談に同席し、技術説明を甲、関係構築を乙が担当する。
  3. 紹介型：乙が顧客を甲に紹介し、甲が役務を提供のうえ、乙に紹介手数料を支払う。

第5条（役割分担）

  1. 甲は、本サービスの測定・分析・レポート生成・システム運用・技術的保守を担当する。
  2. 乙は、エンドユーザーの開拓・提案・受注・関係維持、及び診断結果に基づく改善施策（広告・SEO・制作等）の提案・実行を担当する。
  3. 甲は、乙に対し販売支援キット（提案資料、料金表、FAQ、営業トーク、デモ画面、レポート雛形）を提供する。

第6条（価格・卸価格・エンド販売価格）

  1. 本サービスの卸価格は別紙1のとおりとする。甲は、30日前までに乙へ書面（電子メールを含む）で通知することにより、卸価格を改定できる。改定は、通知後に成立する新規個別契約から適用する。
  2. 乙は、自己の裁量でエンド販売価格を決定できる。ただし、ブランド価値の毀損を防ぐため、別紙1に定める下限販売価格を下回ってはならない。
  3. エンド販売価格と卸価格の差額は、乙の代理店マージンとする。
  4. 本契約に定める金額は、別段の定めがない限り消費税等を含まない（税別）。〔税込／税別の最終確認〕

第7条（発注・検収・支払）

  1. 乙は、エンドユーザーからの受注後、甲所定の方法により甲へ発注する。甲が受注を承諾した時点で個別契約が成立する。
  2. 甲は、乙に対し卸価格に基づく請求書を発行し、乙は請求書記載の期日までに、甲の指定する銀行口座へ振込送金の方法により支払う。振込手数料は乙の負担とする。
  3. 診断（スポット役務）は納品時、月次サービスは各月末締めをもって役務提供完了とみなす。
  4. 紹介型における紹介手数料の料率・支払時期は別紙1に定める。

第8条（資金の取扱い）

  1. 甲は、原則としてエンドユーザーの資金を預からない。エンドユーザーからの代金は、各当事者が自己の契約関係に基づき直接収受することを原則とする。
  2. 代理受領、収納代行、収益分配、暗号資産（USDC等）による決済その他資金移動を伴うスキームは、本契約の初期対象外とし、実施する場合は資金決済法その他関係法令に関する弁護士の確認を経たうえ、別途書面により合意する。

第9条（表示・広告に関するガードレール）

  1. 乙は、本サービスの提案・広告・営業活動において、次の各号に掲げる表現その他の誇大・誤認を招く表現、又は成果を保証する表現を用いてはならない。
    1. AI検索の順位・掲載・問い合わせ数・売上等を保証する旨の表現
    2. AIボットを100%識別する、AI企業から自動で徴収する旨の表現
    3. Cloudflare「Pay Per Crawl」を完全に再現・完全互換である旨の表現

  2. 乙は、甲が別途提供する表現ガイドライン（NG表現一覧・代替表現）を遵守する。
  3. 乙は、景品表示法その他の広告関連法令を遵守し、エンドユーザーに対し本サービスの機能・限界を正確に説明する。

  1. 甲乙は、本契約に関連して知り得た相手方の技術上・営業上の情報（価格表、顧客情報、システム仕様を含む）を秘密として保持し、事前の書面承諾なく第三者に開示・漏洩してはならない。本条は本契約締結に先立ち締結した秘密保持契約（NDA）を補完するものとし、両者が矛盾する場合はより厳格な定めが優先する。

第14条（禁止事項）
