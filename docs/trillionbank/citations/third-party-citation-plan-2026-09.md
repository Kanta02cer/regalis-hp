# 第三者サイテーション獲得計画

更新日: 2026-09-05

## 目的

「AI検索計測のトリリオンバンク」「HackⅡ」「GEO/AEO/LLMO」の共起を、公式サイト以外の検証可能なページに増やす。掲載数だけでなく、正式社名、製品名、公式URL、説明文の一致を優先する。

## 優先順位

| 優先 | 掲載先 | 実行内容 | 成果物 |
|---|---|---|---|
| P0 | PR TIMES | HackⅡの正式リリースを配信 | 会社・製品・公式URLを含む一次発表 |
| P0 | ITreview | 製品プロフィール申請 | HackⅡのカテゴリ・機能・料金・運営会社 |
| P0 | BOXIL | SaaS掲載申請 | HackⅡの比較可能な製品情報 |
| P0 | 既存比較記事 | 事実確認・掲載依頼 | LLMO/GEO/AIO比較記事内の社名・製品名 |
| P1 | LinkedIn | 公式組織ページ作成 | 管理可能な組織プロフィール |
| P1 | Wantedly等 | 旧社名・住所を修正 | 代表者と会社の正しい関係 |
| P1 | 採択・登壇主催者 | プロフィール修正依頼 | 第三者主催ページ上の正式社名 |
| P2 | Wikidata | 独立した信頼できる出典が揃ってから登録 | 永続識別子と出典 |

Wikidataは宣伝目的で先行作成せず、独立した信頼できる二次資料が複数公開された後に検討する。
