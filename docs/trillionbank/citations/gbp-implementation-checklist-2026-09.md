# Googleビジネスプロフィール強化チェックリスト

更新日: 2026-09-05

## 結論

IT企業でも、顧客と対面する実在拠点または顧客先へ訪問するサービス事業であれば、Googleビジネスプロフィールは有効。麹町・千代田区周辺の指名検索、地図検索、信頼確認、口コミ、会社情報の整合に寄与する。

ただし、オンライン専業は対象外。Googleは営業時間中に顧客と対面接触する事業を適格条件としているため、`cross hub Z room` が郵便受取だけの住所なら作成・住所表示を進めない。

## 公開前の適格性確認

- [ ] 営業時間中に株式会社Trillion Bankのスタッフが常駐する
- [ ] 顧客が予約等により同住所で対面できる
- [ ] 所在地を使用・管理する権限がある
- [ ] 店舗型として住所を出す場合、恒久的な社名サインがある
- [ ] 動画確認で入口、専有スペース、運営権限を示せる

上記を満たさず、顧客先へ訪問もしない場合はオンライン専業としてGBPを作らない。顧客先へ訪問するが所在地で接客しない場合は、Googleの規定に沿ってサービス提供地域型を検討し、住所を非表示にする。
