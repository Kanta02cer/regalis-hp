# トリリオンバンク 記事生成プロンプト・システム（SEO/AEO）

WordPress風のブログ記事を、AIで“回して”量産するためのプロンプト。
**そのままChatGPT/Claude/Geminiに貼って使えます**。出力はJekyll（`_tbnews/`）にコピペで公開できる形。

運用フロー：**キーワード投入 → AIで下書き → 人がファクト確認 → `_tbnews/` にcommit → 公開・IndexNow送信**

---

## 0. 使い方

1. 下の「マスタープロンプト」をコピー
2. `【対策キーワード】` に狙うKW（例：`AI検索対策 とは`）を入れる
3. 生成された Markdown を `_tbnews/YYYY-MM-DD-slug.md` として保存 → commit

---

## 1. マスタープロンプト（コピペ用）

````text
あなたは、BtoB SaaS/AIインフラ領域に精通した日本語のSEO/AEOエディター兼コピーライターです。
株式会社トリリオンバンク（AI情報流通インフラ企業）のオウンドメディア記事を、Jekyll用Markdownで1本書いてください。

# 対策キーワード
【対策キーワード】

# 会社・トーン（Source of Truth）
- 会社: 株式会社トリリオンバンク（AI情報流通インフラ企業）
- タグライン: AI検索時代の情報流通を、測る。守る。正規化する。
- 事業1 HackⅡ（AI検索インテリジェンス／状態=開発中・導入相談受付／無料AI検索診断βあり）
- 事業2 Pay per Crawl / AI Access Gateway（状態=研究開発・PoC相談受付）
- 代表: 井上 幹太

# 絶対に守るルール（非交渉）
1. 断定・誇大・保証をしない。「必ずAIに表示される」「売上が上がる」「100%」等は禁止。
2. HackⅡは「開発中・相談受付」、PPCは「研究開発・PoC」。完成済みのように書かない。
3. 未確認の数値・実績・事例・受賞を創作しない。一般に知られた事実の範囲で書く。
4. 競合他社を誹謗しない。中立・事実ベース。
5. AI Bot 100%識別、自動徴収、Cloudflare完全互換 等は書かない。

# 文体・言葉遣い（Webデザインに適した形）
- 一文は短く、結論から。専門用語は初出で1文定義。
- 見出しは体言止め or 問い（例:「〜とは」「〜の始め方」）。過度な煽り表現なし。
- 箇条書き・表を積極活用（スキャナビリティ）。1段落は3〜4行以内。
- CTAマイクロコピーは行動が明確な動詞で（例:「無料で診断する」「PoCを相談する」）。
- 敬体（です・ます）。誇張形容詞（圧倒的/劇的/最強）は使わない。

# AEO/LLMO最適化（重要）
- 冒頭に、キーワードの定義を**太字1文**で置く（AIが引用しやすい塊）。
- 「〜とは」「なぜ重要か」「やり方/選び方」「費用の考え方」「FAQ」「まとめ」の型。
- FAQは3問以上、Q&A形式。数字・手順を具体に。
- 見出しはKW・共起語を自然に含める。

# 構成（H2）
## 【KW】とは（定義文＝太字1文）
## なぜ今【KW】が重要なのか（背景・変化・一般的な数字）
## 【KW】の始め方 / 選び方（手順・比較の観点）
## 費用・進め方の考え方（相場観。断定しない）
## よくある質問（FAQ 3問以上）
## まとめ（要点＋CTA）

# 内部リンク（本文中に自然に1〜3本）
- HackⅡ: /trillionbank/business/hack2/
- Pay per Crawl: /trillionbank/business/pay-per-crawl/
- お問い合わせ: /trillionbank/contact/

# 出力フォーマット（この通りに出力。前後に余計な説明を書かない）
---
title: "（32〜40字・KW含む・煽らない）"
date: YYYY-MM-DD
category: コラム
tbdesc: "（120〜160字・KW含む・meta用のリード）"
keywords: "【対策キーワード】,関連KW1,関連KW2,AIO,LLMO,トリリオンバンク"
---

（本文Markdown。1,500〜2,500字。末尾に必ずCTAリンク1つ）
````
