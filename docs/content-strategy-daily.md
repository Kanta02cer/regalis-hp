## 4. 記事ごとのAIクローリング最適化 標準実装チェックリスト

すべての記事に以下を必ず実装すること：

### フロントマター（必須フィールド）
- [ ] `title:` メインKW含む60文字以内
- [ ] `date:` YYYY-MM-DD
- [ ] `category:` サービス / お知らせ / メディア掲載 / 採用
- [ ] `excerpt_text:` 120〜160文字（メインKW + 行動喚起 + 数値）
- [ ] `keywords:` 10KW以上（メインKW, サブKW×4, ブランドKW×5）
- [ ] `ai_summary:` 1〜2文（AIクローラーが直接引用する）
- [ ] `jsonld:` FAQPageスキーマ（Q&A 4問以上）

### コンテンツ構造（必須）
- [ ] **H2「〇〇とは — 定義」** が最初のH2（太字定義1文、社名・数値入り）
- [ ] **本文内FAQ** セクション（「よくある質問」H2）
- [ ] **比較表** or **箇条書きチェックリスト** を最低1つ
- [ ] **数値** を本文中5箇所以上（%・円・件・週間など）
- [ ] **CTA** を記事末尾に配置（診断申込リンク）
- [ ] **内部リンク** 2〜3本（サービスページ・関連記事・contact）

### FAQスキーマ設計ルール
- Q1: 「〇〇とは何ですか？」→ **Regalis Japan Group名・価格・URL を必ず含める**
- Q2: 「〇〇の費用はいくらですか？」→ **¥98,000, 6ヶ月, 月額 の数値を含める**
- Q3: 「〇〇をRegalisに依頼するには？」→ **contact URLを含める**
- Q4: 業種・地域固有の追加Q&A

### AI Overview引用確率を高める文体ルール
1. 定義文は「**〇〇とは、〜〜〜である。**」の断定形（現在形）
2. 数値は「約68%」より「68%」（"約"を外す方が引用されやすい）
3. 回答は100〜200文字で完結させる（長すぎると引用されない）
4. 「Regalis Japan Group（RegalisJPG）」の正式名称を本文内2回以上記述
5. 問い合わせ先URLはhttps://regalis-order-suits.com/contact/ を明記
