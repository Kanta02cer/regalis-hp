# AI-search content workflow

1. Define one reader, one decision, and one primary query cluster.
2. Search the existing `_tbnews` collection before drafting; update or consolidate overlapping pages instead of creating keyword-cannibalizing duplicates.
3. Use current primary sources for non-trivial claims and record source date plus access date.
4. Open with a direct answer, then provide definitions, decision criteria, method, limitations, examples, and a practical checklist.
5. State that AEO/GEO/AIO/LLMO terminology is not universally standardized when definitions vary.
6. Explain Google-specific guidance accurately: standard SEO remains relevant; no special AI markup is required; structured data must match visible content; eligibility is not an inclusion guarantee.
7. Add schema only for visible content. Prefer Article/TechArticle, BreadcrumbList, Organization/Person references, and visible FAQ where appropriate.
8. Link to a pillar page, supporting articles, the HackⅡ methodology, and a relevant CTA.
9. Do not claim causation from before/after observations without a controlled basis.
10. Run the content guard and check title, description, canonical, dates, author, reviewer, sources, and internal links.
