# AI-search content workflow

1. Define one reader, one decision, and one primary query cluster.
2. Search `_tbnews`, guides, and service pages to avoid publishing duplicate intent under a new title.
3. Use current primary sources for non-trivial claims and record source, publication/update date, and access date.
4. Open with a direct answer, then cover definitions, decision criteria, method, limitations, examples, and an actionable checklist.
5. State when AEO, GEO, AIO, and LLMO terminology is not standardized.
6. Apply official search guidance accurately: standard SEO remains relevant; no special AI markup guarantees inclusion; structured data must match visible content.
7. Add schema only for content visible on the page. Never create fake ratings, reviews, awards, customers, certifications, FAQs, or offers.
8. Link to a pillar page, supporting articles, methodology, editorial policy, and a relevant CTA.
9. Distinguish measured observation, customer-supplied fact, estimate, interpretation, and roadmap.
10. Run the public facts guard and check title, description, canonical, dates, author, reviewer, sources, and internal links.
