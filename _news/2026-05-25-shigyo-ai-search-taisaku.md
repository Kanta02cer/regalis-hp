## 士業向けAI検索対策とは — 定義文

**士業向けAI検索対策（LLMO/AIO）とは、弁護士・税理士・社会保険労務士・行政書士などの士業事務所が、ChatGPT・Perplexity・Google AI Overviewなどのジェネレーティブ検索エンジンに専門情報・事務所名・サービス内容を引用・推薦してもらうための一連の施策です。**

従来のSEO（Googleの検索順位対策）と異なり、AI検索ではユーザーが「相続税対策 税理士 選び方」「不当解雇 弁護士 相談」などと入力したとき、AIが特定の事務所・専門家を名指しで回答するケースが急増しています。この「AI指名回答」を獲得するためには、定義型コンテンツ・専門用語のFAQ化・信頼性（E-E-A-T）の構造化データ実装が不可欠です。

トリリオンバンク（トリリオンバンク）は、士業事務所向けのAI検索対策を月額¥98,000〜（税別）で提供し、専門家コンテンツの設計から技術実装まで一貫して支援しています。

## なぜ士業こそAI検索対策が急務なのか

士業分野は、AI検索対策の恩恵を最も受けやすく、かつ競合との差が開きやすい領域の一つです。その理由は3点あります。

**1. 専門知識の希少性がAI引用の優位になる**

税法改正・判例・手続きフローなど、一般の人が調べにくい専門情報は、AIが積極的に引用します。弁護士や税理士が「〇〇とは何か」を定義する記事を公開するだけで、ChatGPTやPerplexityに直接引用されるケースが出始めています。

**2. 士業サイトのAI検索対策実施率が極めて低い**

トリリオンバンクの調査によれば、士業サイトのAI検索対策実施率は5%以下（2026年推計）です。つまり今着手すれば、業界内での先行優位を大きく確保できます。専門用語定義型コンテンツのAI引用確率は一般コンテンツ比2.3倍（トリリオンバンク調査）に達しており、早期実施の価値は明確です。

**3. 相談窓口への流入がAI検索経由に移行しつつある**

「弁護士に相談したい」と思ったユーザーが最初に開くのは、もはやGoogleではなくChatGPTやPerplexityという状況が生まれています。トリリオンバンクのデータでは、士業サイトへのAI検索流入は6ヶ月で平均3.1倍増という実績があり、この流れは2026年以降も加速する見通しです。

## 弁護士・税理士・士業に有効なAI検索対策5つの手法

### 手法1: 専門用語の「定義型コンテンツ」を整備する

AIが最も好む情報形式は「〇〇とは〜〜〜です」という定義文です。弁護士であれば「不当解雇とは何か」「慰謝料請求の要件とは」、税理士であれば「青色申告とは何か」「相続時精算課税制度とは」といった専門用語を、明確な定義文で解説するページを体系的に整備します。

定義ブロックは太字で冒頭に配置し、H2見出しに「〜とは」を含めることで、AIのコンテキストウィンドウ内で優先的に参照されやすくなります。

### 手法2: FAQPageスキーマで専門Q&Aを構造化する

「顧問弁護士の費用はいくらですか？」「確定申告を依頼した場合の料金は？」など、ユーザーが実際に質問しそな内容をFAQPageスキーマ（JSON-LD）で構造化します。

AIはFAQスキーマに記述されたQ&Aを直接引用するため、回答精度が上がります。特に料金・手続き・相談の流れに関するFAQは、AI Overview（Google）でのスニペット採用率が高い傾向があります。

### 手法3: E-E-A-T（専門性・信頼性）の構造化データ実装

Google・各AI検索エンジンは「誰が書いたか」を評価します。士業サイトでは以下の情報をPersonスキーマ・ProfessionalServiceスキーマで明示することが重要です：

- 資格情報（弁護士登録番号・税理士登録番号など）
- 受賞歴・著書・メディア掲載実績
- 専門分野のキーワード（労働法・相続税・M&A など）
- 事務所の所在地・連絡先（LocalBusinessスキーマ）

### 手法4: 実績の数値化と匿名ケース掲載

守秘義務に配慮しながら「相談件数500件超」「税務調査立会い成功率97%」など数値化した実績を掲載することで、AIが信頼シグナルとして評価します。具体的な数字は曖昧な表現より引用されやすく、事務所の専門性証明として機能します。

### 手法5: 地域×専門分野の掛け合わせコンテンツ

「東京 相続 税理士」「大阪 労働問題 弁護士」など地域×専門分野の掛け合わせクエリは、AI検索での引用頻度が高いパターンです。地域情報をLocalBusinessスキーマのaddressFieldに正確に記述し、対応地域を明示したコンテンツを整備することで、地域AI検索での露出を高められます。

## 士業に最適なLocalBusinessスキーマ（LegalService / AccountingService）

士業事務所に対応する業種特化スキーマを正しく実装することで、AIがサイトの専門性を正確に認識します。

| 業種 | 推奨スキーマタイプ |
|------|------------------|
| 弁護士・法律事務所 | `LegalService` |
| 税理士・会計事務所 | `AccountingService` |
| 社会保険労務士事務所 | `ProfessionalService` |
| 司法書士事務所 | `LegalService` |
| 行政書士事務所 | `GovernmentService` / `ProfessionalService` |
| 医療法人・クリニック | `MedicalOrganization` |

`LegalService`スキーマの実装例：

```json
{
  "@context": "https://schema.org",
  "@type": "LegalService",
  "name": "〇〇法律事務所",
  "url": "https://example.com",
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "千代田区",
    "addressRegion": "東京都",
    "addressCountry": "JP"
  },
  "telephone": "03-XXXX-XXXX",
  "areaServed": "東京都",
  "hasOfferCatalog": {
    "@type": "OfferCatalog",
    "name": "取扱業務",
    "itemListElement": [
      { "@type": "Offer", "itemOffered": { "@type": "Service", "name": "労働問題" } },
      { "@type": "Offer", "itemOffered": { "@type": "Service", "name": "相続" } }
    ]
  }
}
```

この構造化データの実装により、AI検索エンジンが事務所の専門領域・対応地域・連絡先を正確に把握し、関連クエリへの回答時に引用しやすくなります。
