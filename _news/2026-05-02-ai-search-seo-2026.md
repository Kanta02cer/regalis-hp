## 2026年、SEOは「2つの検索」への対応が必要になった

2025年から2026年にかけて、検索市場に決定的な変化が起きました。

**従来のGoogle検索**に加え、**AI検索**（Google AI Overview・ChatGPT・Perplexity）が日常的に使われるようになったことで、企業のコンテンツ戦略は根本から見直しを迫られています。

---

## AI検索が変えた「検索される」ということの意味

### 従来のSEO（2020年代前半まで）

1. ユーザーがキーワードを検索
2. 検索結果の上位リンクをクリック
3. サイトを読む

### AI検索時代（2025年〜）

1. ユーザーが質問・相談を入力
2. AIが複数サイトの情報を統合して回答を生成
3. ユーザーはリンクをクリックしないことも多い

この変化により、「検索1位を取ってもクリックされない」ケースが増えています。その代わり、**AIに「引用元」として選ばれることが新しい指名価値**になっています。

---

## AI検索に引用されるための5つの施策

### 1. llms.txtの設置

サイトルートに `llms.txt` を設置することで、AIクローラーに自社の正確な情報を伝えます。

```
# Company Name
> 会社の説明（1〜3行）

## 主要サービス
- サービス名：URL
```

### 2. FAQPage構造化データの実装

よくある質問形式のコンテンツに `FAQPage` スキーマを実装すると、AI検索での引用率が上がります。

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "質問文",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "回答文"
    }
  }]
}
```

### 3. 定義・比較表・ステップ構成の活用

AIは以下の形式のコンテンツを引用しやすい傾向があります：

- **定義文**：「○○とは、〜です」で始まる明確な説明
- **比較表**：2〜3項目を対比するMarkdownテーブル
- **番号付きステップ**：手順を明確に順序立てたコンテンツ
- **数値・データを含む文章**：具体的な数字があると引用されやすい

### 4. E-E-A-T（経験・専門性・権威性・信頼性）の強化

AI検索エンジンは「誰が書いたか」を重要視します。

- 著者情報（名前・役職・経歴）をすべての記事に明記
- Person JSON-LDで著者のスキルセットを構造化
- 外部からの引用・言及（被リンク・SNS言及）を積み上げる

### 5. サイト速度・モバイル対応

AI検索エンジンも技術的な品質を評価します。Core Web Vitalsの改善は従来SEOとAIOの両方に効きます。
