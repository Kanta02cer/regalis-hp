## 「AI記事を量産すればSEOに効く」は間違い

2023〜2024年ごろ、「ChatGPTで記事を量産すれば検索流入が増える」という情報が広まりました。しかし実際には、AIが生成しただけの薄いコンテンツはGoogleに評価されず、むしろサイト全体の品質を下げるリスクがあります。

Googleは2024年のアップデートで「大規模に生成されたコンテンツ」を明示的にペナルティの対象としました。問題は「AIで書いたかどうか」ではなく、**「ユーザーにとって価値があるかどうか」**です。

## Regalis Japan Groupのコンテンツ制作フロー

### Phase 1：キーワード設計と記事構成

**担当：戦略チーム（人間）**

1. Google Search Console・キーワードプランナーでターゲットキーワードを選定
2. 検索上位5〜10記事の内容を分析（何が書かれているか・何が足りないか）
3. 「このキーワードで検索する人は何を知りたいのか」を言語化
4. 記事の構成案（H2・H3の骨格）を人間が作成

この段階でのキーワード設計が最も重要です。構成案なしにAIに書かせると方向性がぶれます。

### Phase 2：AIドラフト生成

**担当：AI（Claude / GPT-4o）**

人間が作った構成案と指示をもとに、AIが下書きを生成します。

**AIへの指示例：**
```
以下の構成案に沿って、BtoB向けSEOコンサルタントが書いたような
専門的かつ読みやすい記事を書いてください。

ターゲット：Web担当者（SEO経験1〜2年）
禁止：一般論のみの説明、根拠のない断言
必須：具体的な数字、手順の明示、FAQ形式での締め

[構成案]
...
```

### Phase 3：専門家監修と一次情報の追加

**担当：代表・専門担当者（人間）**

これが最も重要なフェーズです。AIドラフトをベースに：

1. **一次情報の追加**：自社の実績データ・クライアント事例・代表の見解を追記
2. **事実確認**：AIが生成した数字・情報が正確かを確認・修正
3. **差別化要素の追加**：「どこでも読める情報」を「うちでしか言えないこと」に変える
4. **トーンの調整**：ブランドボイスに合わせた言い回しに修正

このフェーズで**記事の「価値」が決まります**。AIドラフトは出発点に過ぎません。

### Phase 4：SEO/AIO技術設定

**担当：テクニカルチーム（人間）**

- メタタイトル・メタディスクリプションの最適化
- 見出し構造の確認（H1〜H3の論理的な階層）
- 内部リンクの設置（関連記事・サービスページへ）
- FAQPage・Article構造化データの実装
- 画像のalt text設定

### Phase 5：公開後の改善

**担当：分析チーム（人間）**

公開から3ヶ月後、以下を確認して記事を改善します：

- Google Search Consoleで表示回数・クリック率を確認
- ChatGPT・Perplexityで関連キーワードを検索し、引用されているか確認
- 読了率・直帰率をGA4で確認
- 必要に応じてコンテンツの追記・タイトル変更

## 品質チェックリスト

記事公開前に以下を確認しています：

- [ ] キーワードが自然な形でタイトル・H2・本文に含まれているか
- [ ] 記事で主張していることに根拠（データ・経験・一次情報）があるか
- [ ] 読者が「で、結局どうすればいいの？」と思わない構成になっているか
- [ ] 内部リンクが2〜5本含まれているか
- [ ] FAQまたはまとめセクションがあるか
- [ ] CTAが自然な形で含まれているか
