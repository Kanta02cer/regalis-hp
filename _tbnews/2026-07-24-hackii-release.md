**株式会社Trillion Bankは、AI検索分析サービス「HackⅡ」のMVP主要機能を検証環境へ展開し、限定商用検証と導入相談の準備を進めています。HackⅡは、選定した質問に対するAI回答本文、引用URL、自社・競合の言及、測定日時・条件を記録し、AI検索上の現在地と改善判断を支援するサービスです。**

## 開発の背景

顧客が企業や商品を比較する場面は、従来の検索結果だけでなく、生成AIによる回答へ広がっています。一方、企業側は次の点を継続的に確認しにくい状態です。

- どの質問で自社が候補に入るか
- どの質問では競合だけが候補になるか
- AIがどのWebページを回答根拠として示すか
- 会社・商品・料金・設備等の説明に不一致がないか
- 情報を改善した後、回答や引用がどのように変化したか

単発でAIへ質問するだけでは、質問、対象AI、日時、競合、回答、引用等の条件が残らず、施策前後の比較や社内説明が難しくなります。

## MVP主要機能の対象

今回のMVPでは、次の基礎機能を中心に検証しています。

| 項目 | 内容 |
|---|---|
| 質問・競合の設定 | 顧客の検討場面に近い質問と比較対象を整理 |
| AI回答の取得・保存 | 回答本文と実行状態を記録 |
| 引用URLの保存 | 回答に提示された情報源を記録 |
| 自社・競合の言及確認 | 同じ質問に対する候補入りを比較 |
| 測定日時・条件の記録 | 後から前提を確認できる状態を整備 |
| 時系列比較 | 同じ考え方で再測定し、変化を確認 |
| 結果共有 | ダッシュボードやCSV等で確認 |

具体的な対応AI、質問数、競合数、測定頻度、出力範囲は、検証状況と契約条件に基づいて案内します。

## システムだけでなく、人による確認を組み合わせる

HackⅡは、測定を完全にシステムだけへ委ねる考え方ではありません。表記揺れ、同名企業、引用URLの分類、公式情報との不一致、競合との差等について、人による確認と分析を組み合わせます。

提供プロセスは、次の流れを基本とします。

1. 顧客・商材・競合・重要質問の確認
2. 質問と測定条件の設計
3. AI回答・引用URLの取得と保存
4. 自社・競合の候補入りと情報差の確認
5. 改善候補の整理
6. 情報更新後の再測定

## 現在の提供状況

HackⅡは、**限定商用検証・導入相談受付**の段階です。

現在の公開説明では、開発済みの基礎機能、担当者による分析、導入時に確定する範囲、確認できない領域を分けています。正式な対応範囲を超えて、すべてのAIサービスや検索面に対応しているとは案内しません。

## お約束しないこと

HackⅡは、次の結果を約束するサービスではありません。

- AI検索での掲載や固定順位
- すべてのAI回答・引用・学習利用の観測
- AI内部の思考や選定理由の特定
- 問い合わせ、予約、売上等の事業成果
- 一つの施策と回答変化の直接的な因果関係

観測できる回答・引用・条件を記録し、企業が次の改善や投資判断を行うための材料を提供します。
